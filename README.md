# Useme Alerts

Useme Alerts is a simple automation tool designed for freelancers. It continuously monitors the [Useme](https://useme.com/) portal for new job offers in your favorite categories.

Instead of manually refreshing the website every few minutes to catch the best freelance jobs, this bot does the work for you. As soon as a new offer is posted, you will instantly receive a notification directly to your Discord server or your Email inbox.

**Key Features:**
- Monitors any selected job categories on the Useme platform.
- Keeps track of seen offers to ensure you never get duplicate alerts for the same job.
- Delivers instant notifications so you can apply first.
- Works completely automatically in the background.
